# 内容风格 — truth 溯源 · 先名后释 · 语言规范

## truth 溯源纪律

三类来源，优先级递减；写作时每条内容必须能归入其一：

1. **方案**（旅行社行程 PDF）：服务内容、含项（Included 逐字引用）、方案指定时刻。
2. **票面**（机票/酒店确认）：航班号、时刻、地址、电话、金额、入住政策。
3. **官方**（政府/景区/场馆官网，写作当时核实）：门票价格与规则、开放时间、限额、物种/面积数字。

规则：

- **指不出来源的数字不写**。典型违规：自创钟点（"约 11:00 抵登山口"）、编排的多步流程、
  臆造的支付方式（"必须现金"）、无源价格（"厕所 S/1–2"）。
- 调研/二手信息可用于**背景解读**（历史、地质、生态），数字一律带"约"，来源列入资料来源页。
- 官方规则会变：出发年份的价格/时段必须当场上官网核，旧调研只能当线索。
- private tour 语境：接送/排队/购票后勤是地接的事，手册**不写散客攻略**（几点排队、怎么打车去机场）；
  只写旅行者自理的事（现金、穿着、点菜、身体状况）与方案承诺的服务。
- 方案与官方矛盾时（如方案写"上午"、官方写"06:00–22:00"）：两说并列如实呈现，不自创说法抹平。

## 先名后释

每个地名/景点在全书**首次出现**处：**中文名 + 原文名 + 一句"这是什么"**（类型 + 一眼身份），
然后才轮到解读性内容。例：

> **皮萨克 Pisac** —— 印加王室庄园遗址 + 山脚集市小镇：山脊上的梯田、居住与仪式空间……

理由：路上读者的最高频动作是拿手册对照路牌/门票/向导的话，靠**专名匹配**；解读是第二优先级。
首现之后可只用其一。日程表格里的站点标签用双行：`<b>中文名<br>原文名</b>`。

## 语言规范（大陆简体）

- 中文为主；保留英文/西语的只有专名原文、航班号、确认号，以及需出示给当地人的语句块。
- 估计值一律"约"，禁 `~`；时长用"小时/分钟"，禁 h/min 混排。
- 货币格式全书统一（如 `S/163`、`US$35`，有无空格选定一种）；单位前空格统一（`≤12 kg`、`45×35×20 cm`）。
- 提防歧义缩略：写"A 型（两扁脚）/ C 型（两圆脚）插座"而非 "A/C 插头"；"提前约 1 个月"而非 "~1 月"。
- 外语菜名/术语首现加注：ceviche（酸橘汁腌鱼）、cuy（烤豚鼠，介意慎点）、garúa（海雾）等。
- 语体口语化但信息精确；忌翻译腔（滥用"被/进行"、超长定语）。

## 章节写法要点

- **每日行程页**：日头（大号日期 + DAY N + 星期 + 地点海拔）→ 当日一句话 → 方案服务/路线表 →
  自理提示（现金/穿着/预订）。时刻只用方案与票面的。
- **目的地阅读页**（reader）：与日程页交错，供"读懂这里"——地形/历史/工程/生态的解读，
  配"现场可观察"清单（把知识变成当场动作）。
- **专题攻略页**：机制类信息（购票规则、参观线路差异）客观呈现选项与差异，不替读者做主。
- **资料来源页**：全书最后一页，列官方链接 + 检索日期 + 图片授权总述。
